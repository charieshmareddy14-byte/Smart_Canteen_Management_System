
# Smart Canteen Management System
## Software Engineering Lab Project

The Smart Canteen Management System is a digital solution for managing food ordering and order processing in a college canteen.

## Main Users

- Student / College Staff
- Canteen Staff
- Administrator

## Main Features

- User Registration and Login
- Digital Menu
- Cart Management
- Food Order Placement
- Order Token Generation
- Order Tracking
- Staff Order Management
- Menu Administration
- Order Records
